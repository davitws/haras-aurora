# Haras Aurora

## Estrutura do projeto

- `index.html`: estrutura semântica e conteúdo da página.
- `style.css`: identidade visual, animações, modais e responsividade.
- `script.js`: aprimoramentos de acessibilidade e interação dos modais.
- `imagens/`: fotografias padronizadas dos cavalos em PNG.

## Observação

Os modais possuem funcionamento base em CSS por meio de `:target`.
O JavaScript funciona como aprimoramento progressivo, permitindo fechar com
Escape, controlar o foco e impedir a rolagem do conteúdo ao fundo.
